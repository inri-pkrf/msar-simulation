# הודעה נכנסת: ניהול המס״ר בשעה הראשונה

סימולציית צ׳אט אינטראקטיבית למסך טוטם אנכי (מגע), המדמה חמ״ל של ניהול מרכז סיוע ראשוני (מס״ר).
5 אירועים עוקבים משלב א׳ (הקמה) ושלב ב׳ (הפעלה שוטפת), עם מדד לחץ חי. התוכן מבוסס על המצגת "מס״ר - מבוא והמאמץ הניהולי".

## הרצה
1. פתחו את התיקייה ב־VS Code (File > Open Folder).
2. התקינו את התוסף Live Server (VS Code יציע אותו אוטומטית).
3. לחיצה ימנית על `index.html` > Open with Live Server.

אפשר גם ללחוץ פעמיים על `index.html`, או להריץ בטרמינל: `python -m http.server 8000` ולפתוח `http://localhost:8000`.

## מבנה
- `index.html` - מבנה המסך
- `css/style.css` - עיצוב
- `js/data.js` - **טקסטי התרחישים** (כאן עורכים תוכן)
- `js/app.js` - לוגיקה. בראש הקובץ: לחץ התחלתי, שינויי לחץ, זמן אי־פעילות

## הפעלה בטוטם
Chrome במצב קיוסק: `chrome --kiosk "file:///.../index.html"`. אפשר גם ללחוץ על הכפתור "מסך מלא" בראש המסך.

## פרסום ב־GitHub Pages
Settings > Pages > Source: Deploy from a branch > main / root. הכתובת תופיע שם אחרי דקה-שתיים.
